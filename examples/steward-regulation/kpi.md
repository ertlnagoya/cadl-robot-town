# サービスの KPI（規制の見直しを許す例）

コース D の §13 で使う。LLM は規則と契約に加えて、規制（憲法の不変条件と定足数）の改正も
提案できる。規制は運営者ではなく規制の担当者が判断する。--decider llm --delegate
rule,contract,regulation では、運営者と規制の担当者のそれぞれに代わって LLM が判断する。

## 第 1 期から

顧客に約束した時間のうちに届く配達を、町全体でできるだけ増やしたい。どの会社の顧客も
取り残さないこと。3 社の投票や憲法の条件（不変条件と定足数）が、顧客のためになる改正を
妨げていると考えるなら、規制の見直しを提案してよい。ただし、規制は 3 社すべてと顧客に
及ぶので、誰がどう影響を受けるかを示すこと。
